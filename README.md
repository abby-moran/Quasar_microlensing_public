Code for reproducing the figures and main results of "Measuring Extragalactic Microlens Masses and Motions in Strongly Lensed Quasar Systems with Intensity Interferometry" for a 0.1M_0 microlens.

Already generated data for the portions which run better on a GPU are in /data, but can also be generated with the various scripts. They can run on CPU or GPU but are very slow on CPU, particularily the II script.
The notebooks for generating figures and main results can be run on either CPU or GPU.
